# فكّر وقارن

لعبة عربية بسيطة لتنمية مهارات المقارنة لدى الأطفال من ٦ إلى ٩ سنوات، ومنهم الأطفال ذوو الإعاقة الذهنية البسيطة. تضم ثلاثة مستويات وخمسة عشر نشاطًا مرئيًا. النتيجة للعبة التعليمية فقط وليست أداة تشخيص.

## تشغيل اللعبة

تحتاج إلى Node.js وBun أو npm.

```sh
bun install
bun run dev
```

لبناء نسخة النشر:

```sh
bun run build
```

## النشر المجاني

يمكن نشر الموقع على GitHub Pages أو Cloudflare Pages أو استضافة ثابتة مجانية تدعم HTTPS. في GitHub Pages، اجعل مسار البناء الأساسي اسم مستودعك، مثل `/think-and-compare/`؛ وفي موقع على جذر النطاق استخدم `/`:

```sh
VITE_BASE_PATH=/think-and-compare/ bun run build
```

ارفع ملفات الموقع الثابتة الناتجة من البناء إلى مجلد النشر الخاص بالاستضافة، مع إبقاء المجلدات الفرعية وأسماء ملفاتها كما هي. لا تستخدم فتح الملفات مباشرةً بـ `file://`؛ ميزات التثبيت والعمل دون اتصال تحتاج موقعًا منشورًا عبر HTTPS. جرّب رابط الموقع بعد النشر، ثم افصل الإنترنت واتبع خطوات الاختبار أدناه.

## اللعب دون إنترنت

اللعبة تُخزّن تقدّمها على الجهاز ولا تحتاج إلى حساب أو قاعدة بيانات أو خدمة مدفوعة. يلزم نشرها على موقع يستخدم HTTPS وفتحها مرةً أولى باتصال بالإنترنت حتى تُحفَظ ملفاتها.

### على Android

1. افتح رابط النسخة المنشورة في Chrome وانتظر تحميل الصفحة.
2. من قائمة المتصفح اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3. بعد اكتمال الفتح الأول، افصل Wi‑Fi وبيانات الهاتف.
4. افتح اللعبة من أيقونتها، ثم جرّب المستويات الثلاثة والأنشطة الخمسة عشر.

### على الحاسوب

1. افتح رابط النسخة المنشورة في Chrome أو Edge، وانتظر تحميل الصفحة.
2. اختر «تثبيت التطبيق» من شريط العنوان أو قائمة المتصفح.
3. افصل الإنترنت، ثم افتح التطبيق المثبّت وجرّب الأنشطة الخمسة عشر.

يجب تجربة النسخة المنشورة؛ معاينة Lovable لا تسجّل عامل الملفات دون إنترنت. تسجيلات الصوت ليست مرفقة في المشروع؛ عند غيابها يظل السؤال المكتوب ظاهرًا، ويمكن تشغيل المؤثر الصوتي اللطيف دون اتصال بعد تهيئة الصفحة.

## ملخص تربوي للعرض

تنتقل الأنشطة من اكتشاف أوجه الشبه، إلى الاختلاف، ثم مقارنة شيئين واختيار المطلوب. تُستخدم صور محلية ورسائل قصيرة، وتسمح اللعبة بإعادة المحاولة بهدوء. تحتسب الإجابات الصحيحة من المحاولة الأولى منفصلةً عن الأنشطة التي احتاجت إعادة، مع حفظ النتيجة محليًا على الجهاز. لا تُجمع بيانات الطفل الشخصية.
